# 🤖 Robô de WhatsApp 100% Gratuito & Vitalício — Finanças Pessoal

Este é o seu **robô oficial e exclusivo** para disparo diário automático das notificações de desempenho das 7 clínicas no seu WhatsApp **(69) 993649158** todos os dias às **18:30h**.

---

### 🟢 Vantagens do Robô:
* **100% Gratuito Para Sempre (R$ 0,00):** Sem mensalidade, sem teste de 14 dias, sem expirar.
* **Seguro & Leve:** Não altera nada no seu computador nem no seu celular.
* **Autônomo:** Conecta uma única vez por QR Code (igual ao WhatsApp Web).

---

### 🚀 Como Executar em 3 Passos Simples:

#### Passo 1: Instalar o Node.js (Caso ainda não tenha no computador)
1. Baixe o instalador gratuito do Node.js: [https://nodejs.org](https://nodejs.org) (versão LTS recomendada).
2. Siga o instalador ("Avançar > Avançar > Concluir").

#### Passo 2: Instalar as Dependências do Robô
Abra o prompt de comando ou terminal dentro da pasta `robo-whatsapp-gratis` e digite:
```bash
npm install
```

#### Passo 3: Iniciar o Robô
No terminal, digite:
```bash
npm start
```
1. O terminal exibirá um **QR Code**.
2. Abra o WhatsApp no seu celular `(69) 993649158` ➔ **Aparelhos Conectados** ➔ **Conectar um aparelho** ➔ Escaneie o QR Code na tela do computador.
3. Pronto! O robô estará **conectado e agendado para as 18:30h todos os dias**.

---

### 🧪 Como Testar o Envio Imediatamente:
Com o robô ligado no terminal:
* Digite a letra **`T`** e aperte **ENTER**.
* O robô enviará na hora o relatório formatado das clínicas para o seu WhatsApp!

---

### ☁️ Como Rodar na Nuvem Gratuita (Para não precisar deixar o PC ligado):
Se você não quiser deixar o computador ligado:
1. Crie uma conta gratuita em [https://render.com](https://render.com).
2. Suba a pasta `robo-whatsapp-gratis` como um **Background Worker (Grátis)**.
3. Ele rodará 24h por dia na nuvem gratuitamente enviando as 18:30h!
